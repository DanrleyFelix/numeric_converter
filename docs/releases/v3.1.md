# Numeric WorkBench v3.1

Stable release focused on performance, editor consistency and easier navigation
through large Numeric and Binary Workbench projects.

## Highlights

- Integrated PSX MIPS R3000A debugger with Run, Pause, Stop, Restart, Step,
  Step Over, runtime configuration and filtered Debug Log.
- Execution, read, write and register-condition breakpoints.
- Stack, memory and register inspection with editable runtime values.
- Viewport-oriented Binary Workbench refreshes for offsets, Bytes, Raw
  Instructions, labels, Symbols and highlighting.
- Indexed Local and Global Symbols with virtualized dialogs and lazy processing.
- Virtualized Variables, Logs and Environment tables with filtering, sorting,
  inline editing and multi-selection.
- Independent Numeric and Binary autosave/completion paths.
- Unicorn native runtime included in the Windows portable build.

## Navigation improvements

Large Assembly files are now easier to inspect without forcing a complete
document recalculation. Navigation can start from Labels, Local or Global Symbol
offsets, Search, Go To, Offset Regions, LBA File System, hazards, branches and
jumps. The current viewport is prioritized, label locations are indexed per tab,
and cached results are reused until the source changes.

Label collapse and expand also keep the visible columns synchronized and request
an immediate refresh only for content that becomes visible.

## Bug fixes and stabilization

- Fixed File Offset and Reference Offset gaps after insertion, deletion, paste,
  undo/redo and temporarily invalid instructions.
- Fixed label folding and scroll synchronization with three or more labels.
- Fixed truncated scrolling after expanding the final label.
- Fixed label deletion leaving incorporated instructions hidden.
- Fixed byte editing regressions involving line removal, multi-line paste,
  cursor position, undo history and Assembly synchronization.
- Fixed stale label controls and highlighting after edits or folding.
- Fixed broad copy and right-click actions clearing the active selection.
- Fixed repeated global Symbol scans and excessive per-Symbol regular
  expressions in common editor paths.
- Fixed scalable dialogs creating permanent widgets for every row.
- Fixed Numeric activity triggering unrelated Binary persistence work.
- Fixed debugger stack address handling, breakpoint workflows, memory following,
  register editing and high-volume log rendering.
- Fixed packaged builds failing to load the Unicorn dynamic library.

## Portable Windows build

The attached Windows x86_64 bundle is portable. Extract the archive and run
`NumericWorkBench.exe`; no installer is required.

## Recommended validation

- Open, edit, save and recover Numeric and Binary workspaces.
- Navigate by label, Symbol, offset, search result, branch and jump.
- Collapse and expand multiple labels while scrolling every visible column.
- Insert, replace and remove Bytes, then verify undo/redo and cursor position.
- Run debugger controls, breakpoints, Stack View, Memory View and Debug Log.
